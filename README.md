One word describing my Wi-Fi, written by `main.ts` to `/output/entry.txt`:

**peekaboo**

Home Wi-Fi plays peekaboo — there in the living room, gone in the bathroom,
back again by the router, gone mid-call. A child's game word for the most
familiar household frustration: the signal appears, vanishes, and reappears
as you move from room to room.

Run it with Node 22:

```sh
node main.ts
```

It writes exactly one word (8 characters, no trailing newline) to
`/output/entry.txt`, deterministically, with no network access.
